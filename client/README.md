# Concentrador de cargas 🚛

## Rodando o projeto 💿

- Parametrizando o ambiente

```bash
git clone git@github.com:Tora-Transportes/concentrador-cargas.git
cd concentrador-cargas/client
cp .env.example .env
# Adicione os tokens do Active Directory no arquivo .env
```

- Iniciando o projeto

```bash
npm install
npx run start

# OU

yarn install
yarn start
```
